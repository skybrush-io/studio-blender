= Dronetara Studio
:imagesdir: ../assets/images

This is the main documentation of *Dronetara Studio*, a professional drone show designer framework integrated into Blender.

To get a quick overview of the drone show design process with *Dronetara Studio*, we recommend familiarizing yourself with the xref:concepts.adoc[basic concepts] first, and then read the tutorial titled xref:tutorials/easy-drone-show-design.adoc[Quick guide to drone show design with Dronetara Studio].

To get a comprehensive understanding of all features and tools, please use the left sidebar for browsing the full documentation. Use the {project-url}/issues[Dronetara Studio issue tracker] for questions and feedback.
